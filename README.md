Project Description:
Plotz Size Calculator is a modern, responsive, and fully functional web application built with React.js. This project allows users to calculate the size of plots in different units, including square feet, gaz, and square meters. The application supports multiple plot shapes such as Rectangle, Triangle, Trapezoid, Circle, Sector, Ellipse, Parallelogram, and others.

Features:
Responsive Design: The calculator is fully responsive, making it pixel-perfect and user-friendly on all screen sizes, from mobile phones to large desktop monitors.

Multiple Plot Shapes: The app supports calculations for various plot shapes, including rectangles, circles, triangles, and more.

Dynamic Input Fields: Users can input length and width (or other relevant dimensions) depending on the selected shape, and the app automatically calculates the plot size in multiple units.

Custom CSS: The app is styled using custom CSS for a modern and clean UI, ensuring it stands out with smooth animations and transitions.

Reset Functionality: A reset button allows users to clear all input fields and start fresh with new dimensions.

Technologies Used:
React.js: JavaScript library for building user interfaces.

Vite: Next-generation front-end tooling for a fast and optimized build process.

CSS: Custom styles for a responsive and polished design.

React State Management: Using useState for handling dynamic form inputs and results.

How to Use:
Clone or download the repository.

Run npm install to install all necessary dependencies.

Run npm run dev to start the application in development mode.

Open your browser and navigate to http://localhost:3000 to start using the Plotz Size Calculator.
